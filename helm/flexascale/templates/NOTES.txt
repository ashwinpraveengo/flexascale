1. Check the operator and the services it selected:
   kubectl -n {{ .Release.Namespace }} logs deploy/{{ .Release.Name }}-operator | head -40

2. Inspect proposed decisions (JSON lines, one per service per step):
   kubectl -n {{ .Release.Namespace }} exec deploy/{{ .Release.Name }}-operator -- tail -n 20 /var/log/flexascale/decisions.jsonl

3. Controller ownership:
   kubectl -n {{ .Values.policy.namespace }} get lease flexascale-{{ .Values.policy.name }}
   kubectl -n {{ .Values.policy.namespace }} get hpa -o custom-columns=NAME:.metadata.name,MIN:.spec.minReplicas,MAX:.spec.maxReplicas,FROZEN_BY:.metadata.annotations.flexascale\.io/frozen-by

{{- if eq .Values.policy.mode "observe" }}

4. Enable live control only after reviewing step 2:
   helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reuse-values --set policy.mode=live
{{- end }}

Return control to native HPA at any time:
   helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reuse-values --set policy.mode=observe
Uninstall (the operator restores frozen HPAs on shutdown; the application is not touched):
   helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
